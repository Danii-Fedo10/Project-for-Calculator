# Dan Calculator

A browser-based calculator with standard arithmetic, grouped expressions, powers,
and scientific functions.

## Scientific functions

- Trigonometry: `sin`, `cos`, `tan` and their inverse functions
- Angle mode: switch between degrees (`DEG`) and radians (`RAD`)
- Other functions: square root, natural logarithm (`ln`), base-10 logarithm
  (`log`) and exponential (`exp`, meaning e to the power of the input)
- Constants: π and e
- Powers: use `xʸ` for any exponent and `x²` to square the current expression
- Parentheses can be used to group expressions

Use the on-screen buttons to enter expressions. The keyboard also supports
digits, decimal points, arithmetic operators, parentheses, powers, Enter to
calculate, Backspace to delete, and Escape to clear.
